Политика конфиденциальности

Эта политика описывает личное подключение AR QA Lab OpenClaw к Google Drive. Проект сопровождает владелец аккаунта musai-rus. Сайт предназначен для информации о подключении, а не для размещения исследовательских данных.

Какие данные используются

  • Адрес и идентификатор авторизованного Google-аккаунта для выбора правильного подключения.
  • Данные файлов, созданных приложением или явно предоставленных ему пользователем в рамках разрешения drive.file: содержимое, названия, идентификаторы, ссылки, размеры и контрольные суммы.
  • Публичные документы и страницы, найденные по заданию пользователя; исходные URL, даты получения, редакции и заметки об источниках.
  • Задания, отчёты и связи между выводами и источниками.
  • Токены авторизации, необходимые для работы с Google API. Они не включаются в отчёты, публичный репозиторий или содержимое сайта.

Для чего используются данные

Только для выполнения порученных исследований, сохранения и поиска материалов, предотвращения дубликатов и создания проверяемых отчётов. Приложение не предназначено для просмотра всего Диска, рекламного профилирования или продажи данных.

Где хранятся данные

Оригиналы и отчёты сохраняются в выделенном архиве на Google Drive пользователя. На компьютере, где работает OpenClaw, остаются служебный индекс и журналы работы. В текущей настройке секреты подключения хранятся системным хранилищем ключей macOS через gog; временные файлы загрузки удаляются после операции.

Владелец может остановить подключение, удалить локальные служебные данные и управлять сроком хранения архива самостоятельно. Автоматическое удаление ранее сохранённых документов инструментами архива не выполняется.

Кому могут передаваться данные

Google получает данные, необходимые для авторизации и работы с Google Drive. OpenClaw и выбранный пользователем поставщик ИИ обрабатывают задания, результаты инструментов и необходимые для исследования материалы. В текущей настройке используется OpenAI API. В подключённом Slack могут публиковаться порученные пользователем итоги и ссылки на архив.

Публичный сайт не получает OAuth-токены и не имеет доступа к архиву. Материалы исследований не размещаются в репозитории сайта. Иные передачи или публикации должны выполняться только по поручению пользователя.

Ограниченное использование данных Google

Использование данных, полученных через Google API, и их передача другим приложениям должны соответствовать Google API Services User Data Policy, включая требования Limited Use. Подключение не использует данные Google для рекламы и не предназначено для обучения обобщённых моделей ИИ на этих данных. Доступные материалы используются для конкретных задач пользователя.

Как отключить доступ и удалить данные

  1. Отозвать разрешение AR QA Lab OpenClaw в настройках подключений Google-аккаунта.
  2. Отключить сервер архива в OpenClaw и удалить его локальные настройки и токены, если они больше не нужны.
  3. Удалить файлы архива средствами Google Drive. Отзыв разрешения сам по себе не удаляет ранее сохранённые документы, отчёты или журналы.

Этот сайт

Страницы размещены на GitHub Pages. В них не встроены аналитика, рекламные трекеры, формы сбора данных или внешние шрифты. GitHub может обрабатывать технические сведения о посещениях по собственной политике конфиденциальности.

Вопросы и изменения

Обращения принимаются через репозиторий сайта. Не добавляйте в публичные обращения личные материалы или секреты. При изменении поведения подключения эта политика должна быть обновлена с указанием даты.
